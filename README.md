# StageCue

StageCue shows the choir which song section they are in, and what comes next, over the lyrics in ProPresenter. It follows the locators in Ableton Live.

This repository only holds the installers. **[Download the latest version](../../releases/latest)**.

| You are… | Download |
|---|---|
| **Media team**, on the computer that runs ProPresenter (Mac with Apple silicon: M1 or newer) | `StageCue-<version>-arm64.dmg` |
| **Playback engineer**, on the Mac that runs Ableton Live | `StageCue-Ableton-<version>.pkg` |
| **Playback engineer**, on a Windows PC that runs Ableton Live | `StageCue-Ableton-<version>.exe` |

## Updating

The StageCue app checks here for new versions. When one is out, its **Setup** page shows a banner with a **Download** button. Quit StageCue, then drag the new StageCue into Applications and replace the old one. Your settings stay.

## First time on a Mac

These builds are not signed by Apple yet. If macOS says it cannot open StageCue or the installer, open **System Settings › Privacy & Security**, scroll down, and click **Open Anyway**.
